# 0009 — Haki (Armamento / Observação / Conquistador)

Adiciona campos de Tier e Estado dos três tipos de Haki na ficha do personagem.

```sql
alter table public.characters
  add column if not exists haki_armamento_tier text,
  add column if not exists haki_armamento_state text,
  add column if not exists haki_observacao_tier text,
  add column if not exists haki_observacao_state text,
  add column if not exists haki_conquistador_tier text,
  add column if not exists haki_conquistador_state text;
```

Valores esperados para `tier`: `TIER_II`, `TIER_III`, `TIER_IV`, `TIER_V`, `TIER_VI`, `TIER_VII`, `TIER_VIII`, `TIER_IX`, `TIER_X`, `TIER_XX`.
Valores esperados para `state`: `Dormente`, `Despertado`, `Controlado`.
